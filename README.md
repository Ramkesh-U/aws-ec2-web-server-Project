AWS EC2 Web Server Deployment
Project Description

This project demonstrates the deployment of a basic Linux web server using Amazon EC2. An Amazon Linux EC2 instance was launched and configured with Apache HTTP Server to host a simple webpage. Security Groups were configured to allow SSH access for server administration and HTTP access for the website.

The project also includes basic Linux server administration, Apache service management, network connectivity testing, and website deployment.

AWS Services & Technologies Used
Amazon EC2
Amazon Linux
Security Groups
Apache HTTP Server
SSH
HTTP
Linux / Bash
Project Implementation
Launched an Amazon Linux EC2 instance.
Configured a Security Group with SSH (port 22) and HTTP (port 80) access.
Connected to the EC2 instance using EC2 Instance Connect.
Installed and configured Apache HTTP Server.
Created and deployed a basic HTML webpage.
Started and enabled the Apache service using systemctl.
Tested the web server using a web browser and Linux commands.
Project Output

The deployed webpage was successfully accessed through the EC2 instance's public IPv4 address.
